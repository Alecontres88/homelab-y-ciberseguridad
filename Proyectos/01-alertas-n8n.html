# Sistema de Alertas Automatizadas con n8n y Telegram ## Descripción del Proyecto Diseño de un flujo de automatización para monitorizar la infraestructura local. El sistema evalúa el estado de los servicios y envía notificaciones estructuradas en tiempo real. Este despliegue simula el envío de alertas críticas en un Centro de Operaciones de Seguridad (SOC). Con esto se garantiza una visibilidad constante de los sistemas. ## Entorno y Tecnologías - **Hardware:** Raspberry Pi 3 Model B+ - **Orquestación:** n8n (Nodos Schedule y HTTP Request) - **Scripting:** Python para recopilar métricas locales y automatizar tareas. - **Notificaciones:** API de Telegram (vía BotFather). ## Arquitectura del Flujo 1. **Disparador (Trigger):** Un nodo *Schedule* en n8n inicia el flujo a intervalos regulares. 2. **Procesamiento:** Varios scripts en Python evalúan las condiciones del sistema. Después, n8n recoge estas métricas y las formatea en un mensaje JSON. 3. **Notificación (Output):** Un nodo *HTTP Request* realiza una llamada POST a la API de Telegram. Esto envía la alerta formateada directamente al móvil del administrador. ## Valor Técnico Este proyecto demuestra capacidad real para: - Integrar servicios independientes mediante APIs. - Aislar cargas de trabajo en hardware de bajo consumo. - Automatizar la respuesta a eventos del sistema. - Reducir el tiempo de reacción ante anomalías en la red.
